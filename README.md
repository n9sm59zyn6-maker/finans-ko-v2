# Finans Koçu — Web

Render üzerinde doğrudan yayınlanabilen, build gerektirmeyen statik web uygulaması.

## Özellikler
- Genel bakış / dashboard
- Gelir ve gider ekleme
- Kategori bazlı harcama grafiği
- Bütçe görünümü
- AI Finans Koçu demo motoru
- Fiş yükleme arayüzü (OCR entegrasyonuna hazır)
- Pro alanı
- localStorage ile tarayıcıda veri saklama
- Mobil uyumlu tasarım

## Render
1. GitHub'a bu klasördeki dosyaları yükle.
2. Render → New → Static Site.
3. Repository'yi seç.
4. Build Command: boş bırak.
5. Publish Directory: `.`
6. Deploy.

Bu sürüm frontend/MVP'dir. Gerçek AI API, kullanıcı hesapları, bulut senkronizasyonu, OCR ve Google Play Billing sonraki backend entegrasyonlarıdır.
